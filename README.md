### 👨‍💻 About Me

I am a computer science student at the **Faculty of Science and Technology, UIN Salatiga**, passionate about building independent software tools, managing Linux environments, and exploring logic-driven systems. 

- 🐧 **Daily Driver:** Running **Fedora Linux** as my primary OS for coding, terminal workflows, and system exploration.
- 🔭 **Currently working on:** Standalone Python CLI utilities, web information systems, and simple 2D pixel games.
- 🌱 **Currently exploring:** Software Engineering, Linux System Administration (`systemd`, SELinux, Podman), Computational Logic, and Machine Learning.
- 🎮 **Creative side:** Experimenting with pixel art game mechanics using **Godot Engine**.
- ⚡ **Philosophy:** I prefer building lightweight, self-hosted tools over relying on third-party web wrappers.
